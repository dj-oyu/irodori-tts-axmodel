# テスト観点 — Irodori-TTS axmodel 量子化の検証手順とハマりどころ

> 本書は「量子化した axmodel をどう検証するか」の観点・手順・落とし穴を網羅したチェックリスト。
> 背景の知見は `QUANTIZATION_NOTES.md`、経緯は `FINDINGS.md`、設計は `デプロイ設計.md`。
> 鉄則: **代用指標を信じず、設定の適用とモデルの同一性をビルド後に必ず実物で確認し、最後は実聴で判定する。**

---

## 0. 指標の信頼度ランキング（最重要）

| 指標 | 知覚との相関 | 使い方 |
|---|---|---|
| per-step cosine（1step v_pred 一致） | ✕ ほぼ無相関 | wiring sanity gate のみ（閾値 0.85）。**品質判定に使わない**（RF 反復で誤差増幅, 0.93→wav破綻） |
| SNR / corr（波形一致） | ✕ 弱い | **破綻検出のみ**。時間/位相シフトで暴れる（透明な短文が −2.65dB のこともある） |
| precision_analysis PerLayer | ✕ 楽観的な嘘 | 使わない（float 入力単独評価。0.9997 でも実 end-to-end 0.45） |
| precision_analysis EndToEnd | △ 早期 op のみ可 | 累積指標。**深い op は濡れ衣**。早期 seed（cos/cat/silu 等）だけ読む |
| **mel_L1**（対数メル誤差） | ◎ 良い | **量子化品質の数値 proxy はこれ**（短1.33=透明 / 中2.16=電話 / 長3.68=劣化, true-A16で2.73） |
| **実聴** | ◎◎ 最終判定 | **出荷可否は必ず耳で**。声質・明瞭度・ノイズ（くぐもり/bubbling/ホワイトノイズ）を聴く |

ゲート戦略: **安い順に通す**。ビルド後 precision_analysis の早期 seed を読み、改善が無ければ高価な wav sim（74〜111分）を回さない。

---

## 1. ビルド後の構造検証（sim の前に必ず）

Pulsar2 は config を **silent に無視/部分適用**する。**「設定したつもり」を信用せず実 graph を開く**。

1. **コンパイル成否**: `compiled.axmodel` が生成されたか。ログ末尾 `fuse N subgraph(s)` で **単一 NPU subgraph（CPU fallback 無し）**を確認。
2. **dtype 適用検証**（`scripts/verify_layer_dtypes.py` か `quant/quant_axmodel.onnx` 直読み）:
   - 意図した層が意図 dtype になっているか（例 `node_cos` 入力=U16 / 全FC入力=U16）。
   - intended と実 dtype を **集計して assert**（148指定→146適用 のような silent drop を弾く）。
   - **U16 は heuristic を生き残るが S16 は U8 に降格される**点に注意（活性化を上げるなら U16）。
   - **op の入力精度を上げたいときは op 自身を layer_names 指定**（producer 指定では FC 前 requant が U8 に戻す）。
3. **入力の同一性**（可変長 latent_mask 版）: `latent_mask` が graph input に**生きて残っている**か（all-True だと prune されるので export dummy は partial mask）。
4. **固定 shape の確認**: `x_t` の T が想定通りか（バケツ/可変長の T_max）。

## 2. export 段の数値検証（ビルド前）

- **ONNX vs torch**: `[validate] max_abs_err ~1e-6 / rel ~1e-7` を確認（dynamo export 直後）。1e-4 以上なら export バグ。
- **zeros-vs-real（Option A kv）**: text_state/speaker_state を zeros 化して等価（max_abs_err 0）を assert。KV cache が効いている証拠。
- **mask 書き換え**: `IRODORI_MASK_NEG=-1e4` で additive mask 化して export（finfo.min は量子化レンジを壊す）。
- ※ opset version_converter の RuntimeError が出ても **validate が通っていれば非致命**（中間 opset 変換の警告）。

## 3. wav 本走（唯一の真の arbiter）

`scripts/full_loop_axmodel.py`: fp32 torch を ref に、各 denoiser step を compiled.axmodel（`pulsar2 run` x86 sim）で差し替えてフル sampling → SNR/corr/mel_L1 + wav 出力。

**ハーネス衛生（過去の事故防止）**:
- `AXMODEL_DIR` / `SYNTH_TEXT` / `SYNTH_SEED` / `SIM_ROOT` を **env で渡す**（ハードコード禁止）。
- 起動時に `[config]` print + `assert compiled.axmodel 存在` ガード（**別モデルを 75分測る事故**を防ぐ。
  症状: 結果が別ビルドと **bit 一致** → routing ミスを疑え）。
- v_pred の reshape は `(1, -1, 32)` で **T を出力サイズから推論**（T=119 ハードコード禁止）。
- step0 wiring check: axmodel-vs-torch cosine ≥ **0.85**（下回れば abort＝配線/設定ミス。正常なら ~0.997）。
- **fresh SIM_ROOT** を使い前回結果を上書きしない（forensic 保全）。
- 所要: 1本 **約 74分（T=119）〜111分（T=201）**。T に比例。

## 4. 品質は文長依存 → 短/中/長で測る

- 量子化品質は **T が大きいほど劣化**（HF欠落=くぐもりが累積）。**短(T~37)/中(T~110)/長(T~201)** の3点は最低限。
- **クリーンな fp32 baseline を使う**: 一部の text/seed は fp32 でも破綻/反復するので、まず fp32 で正常な発話を選ぶ
  （`こんにちは、テストです。`+seed1234 は不運な反復例。短文に長 T を当てると反復する）。
- A/B は **同 step 数・同 seed・同 text** で量子化版 vs fp32版（差＝純粋な量子化誤差）。

## 5. 合成設定の観点（reference 品質に効く）

- **num_steps**: 8=高速だが undercooked（検証用）。**40=本番品質**。sim コストは step 数に比例。
- **no_ref + cfg_scale_speaker**: 本来は voice cloning（参照音声前提）。no_ref 時は cfg_scale_speaker の扱いに注意。
- **seed**: 一部 seed は不運（崩れ/反復/声質差）。**複数 seed を試聴**して代表を選ぶ。
- **text 長 vs duration**: 短文に長 duration を強制すると **無音でなく引き伸ばし/反復**（seconds override の罠）。

## 6. DACVAE（ボコーダ）の観点

- **単一パス**（RF 反復なし）→ 量子化が DiT より素直。W8A8+実calib で実用レベル（少しホワイトノイズ・音声良好）。
- **実 latent で calib**（ランダム calib は cosine 4.8dB→実calib 5.96dB）。`scripts/capture_dacvae_io.py`。
- **precision_analysis は OFF で建てる**（Snake-path の `AxQuantizedSub` が uint16 overflow でビルド停止）。
- sim は `scripts/dacvae_sim.py`（単一 `pulsar2 run`, T=119 で >10分・timeout は 2400 に）。fp32 ref と SNR/mel_L1/実聴で比較。
- cos→U16 は **DACVAE には不要**（Snake cos の角度が小レンジ＝U8 で足りる。DiT の timestep cos とは別）。

## 7. 可変長（latent_mask）の観点

- `scripts/test_latent_mask.py`: max-T で生成し latent_mask valid=[:T_real] を毎 step 注入 →
  **有効領域が直接 T_real 生成と cosine 1.0（ビット一致）** を確認済（fp32）。余剰は garbage だが **trim** で捨てる。
- axmodel 側検証（pending）: latent_mask 入り axmodel（53入力）で valid 領域がネイティブ同一かをフル loop で確認。
- calib: latent_mask は **bool dtype**（uint8 だと「dtype 不一致」でビルド停止）。全 calib サンプル full-valid。

## 8. ビルド工程の観点（運用）

- **no-checkpoint**: Pulsar2 ビルドは途中保存が無い → **途中 kill = 全ロス**。質問は kill 命令ではない。長ビルドは完走させる
  （メモリ: process-intervention-criteria）。
- **OOM 監視**: 本ホスト 15GB（実効 ~9GB）。**長 T + U16 活性化 + AdaRound** は OOM（実績 long+true-A16+AdaRound 4h で OOM）。
- **AdaRound は本環境で不調**: OOM か、calib を削ると NaN scale（calib16 で `v_pred x_scale=nan`）。S8 重み床は越えられず。
- **GPU calib**（`device:cuda:0`）でビルド大幅高速化（~15分）。precision_analysis ON は +~9分。

## 9. 過去に騙された落とし穴（再発防止リスト）

| # | 騙された事 | 真相 / 対策 |
|---|---|---|
| 1 | PerLayer cosine 0.9997「ほぼ完璧」 | 嘘。EndToEnd で 0.45。**EndToEnd を見る** |
| 2 | per-step 0.93「もう少し」 | wav 破綻 −4.93dB。**per-step は品質 proxy 不可** |
| 3 | wav −4.93dB（mixedp 初回） | **別モデルを測っていた**（ハードコード路）。bit一致で発覚→`[config]`ガード |
| 4 | mixedp 148指定→効かず | 146 だけ適用（cond 脱落）。**ビルド後 dtype 検証** |
| 5 | SNR −2.65dB の短文 | 実聴は透明。**SNR は知覚 proxy 不可、mel_L1/実聴で** |
| 6 | 「DACVAE も cos U8 バグ」仮説 | 外れ（B0≈B1）。Snake cos は小レンジ。**値の大きさを実測してから転用** |
| 7 | global op_types S16 で A16 化 | 大半 U8 のまま（heuristic 降格）。**U16 + layer_names で FC を直接** |
| 8 | true-A16 partial で「効果なし」 | partial すぎただけ。full(245FC)で mel 3.68→2.73。**coverage を実測** |
